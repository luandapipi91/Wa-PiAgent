✨ Fun features

Serious work, seriously fun

Powerful doesn't have to be stern. WA PI Agent treats "easy to use" and "fun" as first-class requirements.

Task-complete easter egg

🐸 Task done? A frog drops by

Every time a conversation finishes, a frog hops out from a random corner of the chat area — jumping, waving, napping, or sitting — with a sound cue that says "done". Prefer silence? One switch in Appearance settings turns it off.

Buy now Picked · Send to chat →
Designer favorite

🎯 WYSIWYG page editing

AI-generated pages render live in the preview panel: hover to highlight any element, then click it (or pick its parent) to send it straight to the chat. Instead of a screenshot, the AI receives a locator precise to the source line — even for elements nested inside iframes, so fixes always land in the right place.

Multi-agent collaboration

🤖 An agent squad — assign with @

Give every agent its own avatar, prompt, tool allowlist, and skills to form your AI squad. Type @ in the chat box to assign whoever you need; agents can also delegate to and collaborate with each other — you're the commander, they divide up the work.

Scheduled automation

⏰ Run tasks on a schedule, results in your chat

Hand repetitive work to Automation: agents run on a schedule with success / failure / running states at a glance; when a task completes, an IM bot pushes the results into your WeCom group — the work gets done even when you're away from your desk.

🔌

MCP, one click away

stdio / HTTP transports, connection tests and live tool lists — errors explained in plain language, not stack traces.

💲

Skills at your fingertips

Type $ in the input box to open the skill panel; built-in and personal skills are discovered automatically.

🧠

Memory that grows

Global / project two-level memory keeps preferences and conventions accurate — the more you use it, the better it knows you.

🛡️

Local-first

Sessions, configs, and memory all stay on your own machine. Nothing is uploaded to any server.

🚀 Getting started

Four steps to your first chat

Everything is configured in "Settings" with a few clicks; changes take effect immediately.

1

Configure a model

Settings → Model management → "+ Add provider", choose OpenAI-compatible or Anthropic, paste your API key, then hit "Test connection" and look for the ✓.

Settings → ModelsTest connection ✓
2

Connect MCP

Settings → MCP connectors → "+ Add manually", pick the stdio or HTTP transport, then "Test connection" and "View tools" to confirm everything is ready.

~/.pi/agent/mcp.jsonproject-level .mcp.json
3

Use skills

Skills inside skill directories load automatically. Type $ in the chat box to open the skill panel, pick one, and send — a directory is all it takes.

~/.pi/agent/skillstype $ in the chat box
4

Build your own agents

Create an agent: write its prompt, pick a tool allowlist, bind skills, and form a "relationship web". Type @ in the chat to summon one — agents can even delegate work to each other.

~/.pi/agent/agentstype @ in the chat box
⚙️ Settings tour

Every switch, worth knowing

Four high-frequency sections in Settings, each with its own job.

🎛️General

  • Language: 中文 / English, instant switch
  • Sounds: task done, needs action — with preview
  • Auto-retry with exponential backoff on network errors
  • Export turns & image export options
  • System proxy · Launch at login

🎨Appearance

  • Theme: follow system / light / dark
  • Accent color: click to pick your favorite
  • Font size: scales text only, never the layout
  • Collapse tool calls by default for a cleaner view
  • Task-complete animation: the frog toggle

🧩Plugins

  • Install with an npm package name, one click
  • Upgrade badges when new versions ship
  • Streaming logs during install / upgrade
  • Toggle extra slash commands item by item
  • Install / uninstall / upgrade takes effect in the current conversation

📮Share

  • Two channels: EdgeOne Pages / Cloudflare Pages
  • "Deploy now" with just an API token
  • Publish artifacts as public links (~1–2 minutes)
  • Optional custom domain
  • Manage everything in "My shares"
🌱 Growing

What we're improving next

The roadmap is a set of prioritized bets, not a contract — but every step heads toward "easier to use".

🌿

Session branching In design

The engine already supports history branching. We're building a visual interface to branch from any point, compare paths, and travel back in time — so every line of thought is safe to explore.

🔗

Project connectors Planned

An out-of-the-box connector marketplace on top of MCP: more IM platforms, more SaaS services — configure and go, so projects connect to the world naturally.

💬

IM bots WeCom is live

The WeCom bot already runs on persistent connections. WeChat, Feishu (Lark), and QQ are on the way — put your agents where your team already talks.

Minimalism, by design

A powerful engine deserves an interface that never gets in the way. We cut everything that stands between you and the task: no command line, no config hell — and all data stays on your own computer.
