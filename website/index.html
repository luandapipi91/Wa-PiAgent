🚀 上手指南

四步开聊，不写一行配置

所有配置都在「系统设置」里点点鼠标完成，改动即时生效。

1

配置模型

系统设置 → 模型管理 → 「+ 添加供应商」，选 OpenAI 兼容 或 Anthropic 格式， 贴入 API Key，点「测试连接」看到 ✓ 连接成功就能开聊。

设置 → 模型管理测试连接 ✓
2

连接 MCP

系统设置 → MCP 连接器 → 「+ 手动添加」，选 stdio 或 HTTP 传输， 保存后「连接测试」，「查看工具」确认工具已就绪。

~/.pi/agent/mcp.json项目级 .mcp.json
3

调用技能

技能目录里的技能自动加载。在聊天输入框敲 $ 唤起技能面板， 选中生成技能标记，发送即调用——目录即技能，放进去就能用。

~/.pi/agent/skills输入框敲 $
4

组建自己的智能体

新建智能体：写提示词、挑工具白名单、绑技能、组「关系网」。 聊天时敲 @ 唤起，智能体之间还能互相委托组队干活。

~/.pi/agent/agents输入框敲 @
⚙️ 设置一览

每个开关，都值得你知道

系统设置里的四个高频分区，各管一摊、互不打扰。

🎛️通用

  • 语言：中文 / English 即时切换
  • 提示音：任务完成、需要操作，可试听
  • 自动重试：断网超时自动按间隔翻倍重试

  • 使用系统代理 · 开机自启

  • 界面主题：跟随系统 / 浅色 / 深色
  • 主题颜色：点选喜欢的强调色
  • 文字大小：只缩放文字不改布局
  • 回复过程默认折叠，界面更清爽
  • 任务完成动画：青蛙蹦出开关
