> 状态：已完成（2026-10-09，选型已落地）
> 现状模型（升级后）：Xenova/bge-base-zh-v1.5（q8，768 维，CLS pooling）
> 原模型：Xenova/bge-small-zh-v1.5（q8，512 维，mean pooling）

> ⚠️ 本文件曾在 2026-10-09 丢失（未入库文件在多会话共享工作区被清理），现已重建并入库。

## 1. 根因分析：bge-small-zh-v1.5 相关性为什么「感觉不准」

### 1.1 测量勘误（重要）

排查初期的「精确余弦」实测全部作废：探针把 `embedQuery` 返回的 Uint8Array
（Float32 小端字节表示）误当字节向量计算余弦。归一化向量的字节模式高度相似，
任何文本对的「字节余弦」都挤在 0.75+——由此得出「区分度崩坏 ±0.004、英文完全
不可用」的 v1 假结论。修正为 Float32 余弦后：既有测试「无关句 cos<0.4」一直是
绿的（真实口径），与 v1 数据的矛盾即源于此。

### 1.2 修正后的真实数据（Float32 余弦）

**① 查询-文档区分度（embedQuery 口径，含指令前缀，查询「上线前要做什么质量检查」）**

| 档位 | cos | 排序 |
|---|---|---|
| 强相关（发版流程需要先跑单元测试和四层测试） | 0.4359 | #1 |
| 弱相关（Go 工具链安装在 D 盘…） | 0.3866 | #2 |
| 无关（今天中午吃了红烧牛肉面） | 0.3550 | #3 |
| 无关（涨停板战法与集合竞价挂单技巧） | 0.2392 | #4 |

区分度间隔 **+0.08**，排序完全正确——模型判别力正常。

**② 指令前缀对照**：无前缀间隔更大（+0.17 vs +0.08），绝对分布更高（0.23~0.48）；
有前缀整体压低（0.24~0.44）。官方 s2p 任务建议加 query 前缀，保留现状。

**③ 英文**：英文同义 0.6135 > 英文无关 0.5060 > 中文无关 0.3681——**排序正确、
可用**（弱于中文，不是「完全不可用」）。

**④ 量化近似忠实**：q8 量化 scanDistance 与精确 1−cos 偏差 ≤0.0013（6 样本实测）。
bge-small 真实分布（同查询 6 语料）：0.5139~0.7422，强相关 0.5910 与部分无关条目
（0.5139 / 0.5942）重叠。

**⑤ 官方资料佐证（HF 模型卡）**：v1.5 温度 0.01 对比学习使相似度分布大致在
[0.6, 1]，官方明示「>0.5 不代表两句相似」「重要的是相对排序而非绝对值」；
训练语料标注 Chinese；指令前缀不加仅轻微下降，最佳做法按任务实测。

### 1.3 根因结论

1. **真实短板＝中档排序能力有限**：bge-small-zh-v1.5（33M）在同域短文本场景下
   强相关与部分无关条目的距离重叠（0.51~0.63 混叠），bench hit@1 仅 0.73——
   小模型的中档分辨力天花板，非崩坏。
2. **pooling 口径偏差**：生产用 mean，bge 官方推荐 [CLS]——同模型换 CLS 即
   hit@1 0.73→0.82、hit@3 0.73→1.00（bench 实测，零成本）。
3. **量化无损**：偏差 ≤0.0013，q8 继续用。
4. **英文可用但弱**：排序正确，无需为此单独换双语模型（双语候选加分照旧）。
5. **阈值层面**：0.51~0.74 分布下，0.8 门槛确实只能拦极远域（该结论成立）。

## 2. 候选调研

筛选条件：≤200MB（q8/quantized 口径，HF blobs 实测）、transformers.js/ONNX 可用
（Xenova 命名空间）、中文为主双语加分。

| 候选 | 参数量 | q8 体积 | 维度 | 语言 | 入围 |
|---|---|---|---|---|---|
| Xenova/multilingual-e5-small | 118M | 112.8 MB | 384 | 100+ 语言（中英强） | ✅ |
| Xenova/bge-base-zh-v1.5 | 102M | 98.1 MB | 768 | 纯中文（C-MTEB 强） | ✅（中文对照组） |
| Xenova/jina-embeddings-v2-base-zh | 161M | 154.1 MB | 768 | 中英双语专门优化 | ✅ |
| Xenova/paraphrase-multilingual-MiniLM-L12-v2 | 118M | 112.8 MB | 384 | 50+ 语言（老架构，预期弱） | ✅（下限对照） |
| Xenova/bge-m3 | 568M | 543.3 MB | 1024 | 100+ 语言 | ❌ 超限（>200MB） |

备注：全部为 transformers.js 官方适配（feature-extraction 标准管线）；e5 系有
`query: `/`passage: ` 官方前缀要求（embedder 改造点）；维度变化由 embed_meta
指纹机制兜底（不匹配 → 视为未索引 → 存量自动重回填）。

## 3. 评测基准

`scripts/embedding-bench-data.ts`：**21 条语料**（中文技术 6 / 偏好 3 / 执行记录 2 /
干扰 4 + 英文技术 4 / 干扰 2）+ **13 条查询**（中文 8 [含 2 跨语言查英文] /
英文 3 [含 1 跨语言查中文] / 负例 2），三档相关性，可复跑。

评分口径：hit@1 / hit@3 / MRR（正例排名）+ 负例 top-1 cos 与区分度间隔
（相关查询平均 top-1 cos − 负例平均 top-1 cos，判绝对阈值可用性）。

复跑命令：`bun run scripts/eval-embedding-bench.ts`（可选 `--only=配置id`）。

## 4. POC 对比结果（q8 / 各自官方 pooling 与前缀口径）

| 配置 | hit@1 | hit@3 | MRR | 量化分布特征 | 跨语言（q7/q8/q11） |
|---|---|---|---|---|---|
| baseline-bge-small-zh（mean，原状） | 0.73 | 0.73 | 0.774 | 0.51~0.74，中档混叠 | — |
| bge-small-zh-cls（基线换 CLS） | 0.82 | **1.00** | 0.879 | — | — |
| **m2-bge-base-zh（CLS）** | **0.91** | 0.91 | **0.922** | 相关 0.47~0.71 / 无关 0.70~0.73 | #1 / #3 / #3 ✓ |
| m3-jina-zh（mean） | 0.73 | **1.00** | 0.864 | 相关 0.32~0.62 / 无关 0.59~0.76 | **#1 / #2 / #2** ✓ |
| m1-e5-small（mean+e5 前缀） | 0.64 | 0.82 | 0.743 | 挤在 0.88 附近 | #1 / **#10** / **#6** ✗ |
| m4-minilm（mean） | 0.73 | **1.00** | 0.864 | 负例 top-1 高达 0.80（区分度最差） | #1 / #1 / #2 |

关键发现：

1. **排序最优：bge-base-zh-v1.5 q8/CLS**（hit@1 0.91、MRR 0.922），中文全部 #1，
   跨语言可用（#1/#3/#3）
2. **零成本优化**：mean→CLS（bge 官方口径）即基线 hit@3 0.73→1.00、MRR 0.774→0.879
   ——生产 embedder 此前用 mean 是口径偏差
3. **双语最稳：jina-v2-base-zh**（跨语言 #1/#2/#2 全过），但 hit@1 0.73 弱于 bge-base
4. **e5-small 不及预期**：中文核心场景 #4，跨语言 #10/#6
5. **绝对阈值普遍难做**：各候选相关/负例区间均有重叠，距离门槛只拦极远域；换
   bge-base 后分布变宽（0.47~0.71 vs 无关 0.70+），阈值需按新分布重校

## 5. 结论与落地（已完成）

**选型：Xenova/bge-base-zh-v1.5，q8 量化、CLS pooling**（98.1MB ≤ 200MB 预算，768 维）。
依据：排序质量全面第一；跨语言可用；同为 bge 族改造面最小。双语取舎：jina 双语更稳
但 hit@1 落后 0.18，「中文为主」口径下取 bge-base；英文→英文仍 #1，英文→中文弱双语（#3）。

已落地改造：

| 项 | 内容 |
|---|---|
| `embedder.ts` | EMBED_MODEL → Xenova/bge-base-zh-v1.5；pooling mean→cls（query 与 doc 两侧）；选型契约测试钉住 |
| `schema.ts` | EMBED_DIM 512→768 |
| 存量迁移 | embed_meta 指纹（model:dtype:dim）自动失效 → listUnindexed 收录 → 后台重回填；护栏单测：旧 512 字节向量+旧指纹 → 回填后 3072 字节+新指纹 |
| 阈值重校 | SEMANTIC_MAX_DISTANCE 0.8→0.75（bge-base 实测分布：相关/弱相关 0.51~0.62，无关 0.75~0.88，0.75 落在分布间隙） |
| 打包资产 | stage-native-assets.ts 模型名单一来源改引 kernel EMBED_MODEL（内置资产 23MB→98MB） |
| 真实库 | 341 条存量记忆（330 条旧指纹 + 11 条无向量）在下次启动时自动重回填为 768 维新指纹 |

验证状态：
