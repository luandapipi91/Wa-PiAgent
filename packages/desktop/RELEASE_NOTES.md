WA PI Agent 0.5.4 更新内容：

【内核升级 · pi 0.86.0】

- 提示缓存预热：长工具任务与空闲时用低成本刷新保住提示缓存，减少重复计费、加快出词
- 报错反馈：会话内可直接上报问题，诊断信息自动脱敏，可选附带会话记录或导出压缩包
- 按模型配置压缩预算：可为不同模型单独设置预留 token / 近期 token 预算
- 启动更快：重复启动复用编译缓存，`--resume` / `--continue` 的会话列表与继续会话加载更快
- 工具调用更稳：内置 read / bash / powershell / edit / write 默认启用严格 JSON-schema 采样
- 剪贴板改用内置跨平台助手，长文本模糊搜索延迟降低

【新增】

- 预览窗支持拖动移窗与拖拽调整大小，并记住尺寸与位置

【优化】

- token/成本统计与 pi 0.86.0 官方口径对齐（缓存写入等用量条目计入），压缩触发点与自动压缩统一
- 缓存命中率改为整会话累计口径（主代理 + 子代理 + 预热用量合计）
- 流式节流窗口 50ms → 20ms，思考与正文显示更跟手

【修复】

- 修复流式输出中偶发出现「空的思考」块的问题
- 修复预览窗关闭重开后不记住大小/位置的问题
- 修复 pi 0.86.0 会话格式变化导致的统计与展示异常（系统条目过滤等）
