WA PI Agent 0.2.8 更新内容：

【新增】

- 文件分享新增 Cloudflare Pages 渠道：配置 API Token 即可一键部署，生成永久公开链接（单文件 ≤25MB）

【改进】

- 分享渠道配置体验：Token ID 帮助弹窗图文指引、注册入口统一、容量按渠道动态显示（Cloudflare 不限 / EdgeOne 5GB）
- 分享部署进度条改为呼吸脉冲动画，不再误读为进度回退，部署中显示时长预期
- 智能体宫格「新建智能体」按钮移到右下角，操作更顺手
- 弹窗交互优化：点击阴影不再误关（防止输入丢失），所有弹窗补齐右上角关闭按钮

【修复】

- 聊天「卡死」自愈：kernel 崩溃自动重启（先清理端口避免崩溃循环）、SSE 假活看门狗自动重连、崩溃现场日志落盘便于定位
- 本地代理中途失效自动回退直连，网络请求更稳定
- 日志上限按磁盘剩余空间自适应（默认 10MB，磁盘紧张自动缩减）
- 打包版工作区路径不再受打包机环境影响
