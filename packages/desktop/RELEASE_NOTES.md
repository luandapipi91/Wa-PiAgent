WA PI Agent 0.8.7 更新内容:

【改进】

- 底层引擎升级至 1.5.0：工具搜索支持中文等非 ASCII 关键词，MCP 工具检索更精准
- 插件升级后直接在插件卡片上显示本次更新内容，无需去包仓库查更新日志
- 工具检索排序优化：按名字匹配的工具排在更前，长服务器说明不再干扰排序
- 模型目录更新：接入 GPT-6.1 Terra 等新模型；纯实时/图像类模型不再出现在对话模型列表
- 面板内列表（模型/扩展选择器等）支持 PageUp/PageDown 翻动列表项

【修复】

- 依赖安装结果校验加强：装出的内核依赖版本不符时拒绝启动并提示重试，避免新旧内核混跑
- 智谱/Z.ai 套餐用量到顶（code 1308）不再反复无效重试，直接提示等待额度重置
- ChatGPT 个人版用量上限报错正确归类为终止性错误，不再重试
- 多家模型服务修复：Claude 会话偶发报错、Kimi K3.1 Pro 请求参数、GPT-5.4/5.5 切换后工具调用、Bedrock 工具数量上限等
- 会话写入异常时不再丢失历史消息；Windows 路径大小写不一致引发的技能重复加载等问题修复
- 长回复与工具输出流式展示更流畅，渲染占用更低
