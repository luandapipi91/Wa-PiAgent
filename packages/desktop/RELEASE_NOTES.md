WA PI Agent 0.5.5 更新内容：

【新增】

- 记忆按项目隔离：项目身份改为「项目登记表」，同一路径归一后复用同一条记忆；检索默认不跨项目混用
- 记忆全局层只允许「画像」：写入全局的知识/执行记录会被拒绝并给出引导
- 文件树双击图片/视频直接打开媒体画廊；画廊列出同目录的图片与视频，缩略图条支持虚拟滚动（大目录不卡）

【修复】

- 修复新会话一次粘贴/选择多个文件只生效一个的问题
- 修复文件变更清单里点文件路径只是展开/收起 diff（现改为打开预览）
- 修复浮动预览窗里的文件改动不自动刷新的问题
- 修复媒体画廊同一张图重复出现（绝对/相对路径写法不同）
- 修复媒体画廊缩略图破图（默认工作区会话的真实工作目录是子目录）
