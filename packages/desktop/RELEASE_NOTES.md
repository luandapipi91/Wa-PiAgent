【新增】

- MCP 连接器改用内核内置实现：可逐台服务器选择「直接可用 / 脚本调用 / 脚本调用（按需加载）/ 按需加载 / 不暴露」五档暴露方式
- MCP 服务器 OAuth 登录（授权在浏览器中完成）与登出可在应用内发起
- 新增子智能体转录查看：点委托卡片即可打开完整执行过程，按「思考 / 工具 / 正文」筛选，执行中也实时跟进
- 子智能体支持「续聊」：可接着上次的实例继续派任务、保留它的上下文，不必整批重派
- 脚本内调用工具（如 MCP 工具）的嵌套调用在聊天区按层级展示

【改进】

- 内核升级至 pi 1.0.0：MCP 改由内核内置提供，登录与凭据由内核统一管理
- 模型清单的价格与上下文长度不再停在安装那一刻：启动时后台获取最新目录（拉不到就沿用旧数据，不影响使用）
- 项目级 MCP 配置改用官方格式，位于项目内 `.pi/mcp.json`
- `/` 命令菜单不再列出内置的 `/mcp` 与 `/llama`（MCP 请在「MCP 连接器」页管理）

【注意】

- 此前在旧版登录过的 MCP 服务器需要重新登录
- 项目级 MCP 配置需在应用内向该项目授权（需重启会话生效）
