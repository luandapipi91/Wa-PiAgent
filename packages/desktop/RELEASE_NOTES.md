WA PI Agent 0.1.26 更新内容：

【新增】

- 侧边栏「项目|最近」分段切换：最近时间线按时间汇总全部项目会话（按天刻度、标注项目名），跨项目切换会话更便捷；智能体列表折叠为一行「智能体 n ›」，点击打开宫格
- 会话列表重排位置动画：最近视图点击会话、项目视图点击项目名时平滑过渡，不再「闪一下」
- 文件不支持预览时新增「默认方式打开」按钮，用系统默认应用打开文件
- 外链统一在应用内新窗口打开，子窗口加地址栏（显示/复制/修改地址后导航）
- 首启自动下载 Node.js 运行时：无系统 Node.js 的用户首次启动时自动检测网络并从国内源（npmmirror）或官方源下载 Node.js LTS，解决 MCP 服务器（npx -y）在无 Node 环境下报错的问题
- 端口自愈失败时提供「换端口启动」和「退出」选项：启动时固定端口被占用且自动清理失败时，可一键切换到其他可用端口启动，或直接退出应用

【修复】

- /mcp 等扩展命令导致会话卡死（RPC 模式 custom() 挂根治）
- 文件浏览器暗色模式适配（选目录弹窗/附件选择器/文件树）
- 系统设置文字大小不生效于聊天窗口 markdown 正文
- 主回复反引号包裹的裸 URL 不渲染为可点击链接
- 新建页选模型发送后会话界面显示旧模型
- 换端口启动按钮两个 bug（端口未切换 + 按钮并排）

【改进】

- 系统 Node.js 检测改为优先扫描 PATH 环境变量（而非仅检查固定路径），正确识别通过 nvm/scoop/volta 等工具安装的 Node.js
- 有真实 Node.js 时不再生成 bun 兼容包装脚本，直接使用 Node.js 自带的 npm/npx，提升 MCP 服务器兼容性
