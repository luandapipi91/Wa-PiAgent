WA PI Agent 0.9.0 更新内容:

【新增】

- 浏览器操作全面升级：页面快照改成带编号的树形结构，能精确点到每个元素
- 截图支持自动标注编号，看得见就能点到
- 等待条件命中后自动附上页面快照，不用再多问一次模型
- 工具返回的结构化内容自动排版，长文本折叠预览更清爽

【改进】

- 每次点击、输入后自动附页面变化，减少来回确认
- 页面内跳转不再卡住，失败提示更明确
- 点击前会检查目标是否被弹窗遮挡
- 网页原生弹窗自动应答，不打断流程

【修复】

- 修复模型不按编号定位、靠猜 CSS 选择器导致点不到元素的问题
- 修复 MCP 授权过期时按钮错显「登出」
- 修复工具返回文本重复解析、换行错乱的问题
