WA PI Agent 0.2.1 更新内容：

【新增】

- 定时任务（自动化任务）：支持每分钟/每小时/每天/每周等计划类型（可配置间隔与开始时间），提供任务列表、编辑表单、详情视图、执行记录列表与执行过程回放
- 企微机器人通讯录：进站自动采集联系人，通讯录面板查看与重命名备注名，会话列表与顶部显示备注名
- IM 推送 @im-push-to：定时任务/自动化可推送到指定联系人或群，输入框联系人/技能 chip 化
- 扩展「修复依赖」：一键重建扩展依赖，带确认与进度反馈
- 新建会话页右侧文件浏览侧栏
- 最近视图会话右键菜单：重命名、删除、在访达/文件管理器中打开（所有会话，非系统项目打开项目目录、系统项目打开会话子目录）
- 文件预览底部地址栏：显示完整路径，一键复制路径到剪贴板

【改进】

- 系统代理：跨平台自动读取系统代理（修复网页端不生效与 curl 不走代理）
- 记忆字符上限放宽（用户 1800、项目记忆 3200）
- 技能弹窗支持 ↑↓/Enter 键盘导航
- 侧边栏智能体列表置顶：移到「任务|IM」页签之上，跨页签始终可见
- 新建会话入口优化：移除独立「新建会话」按钮，最近视图「今天」刻度右侧提供「＋新建会话」
- 「项目|最近」分段改虚线样式（中间竖线分割、选中文字加粗），与「任务|IM」实心分段区分层级
- 会话列表动画：auto-animate 替换为 motion layout，降低动画启动延迟
- 文件预览不支持页按钮改无边框幽灵风格，操作按钮顺序调整
- 换端口设置持久化记忆
- 外链统一应用内新窗口打开

【修复】

- 折叠/展开项目时会话列表「重影」、项目名与会话动画不一致导致的短暂重叠
- pi 子进程读取不到系统代理，网络请求直连超时
- 弹窗定位撑满屏幕（w-full 循环依赖）
- 外链子窗口 macOS 多屏拖动消失
- 测试连接：失败时错误信息更清晰（附响应体与代理诊断），修复模型匹配
- 长任务完成整轮折叠时滚动位置跳动（内容不在底部）
- 底层引擎升级至 0.84.2（DeepSeek 输出限制字段、Kimi 请求头、流式 usage 统计、扩展工具长输出折叠等修复）
