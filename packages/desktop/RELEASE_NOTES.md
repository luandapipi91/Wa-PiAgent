WA PI Agent 0.1.6 更新内容：

【新增】任务完成 / 需要操作提示音

- 智能体任务完成（agent_end）或有新问题需要你回答（ask_user_question）时播放提示音
- 系统设置 → 通用 可分别开关两种提示音并试听
- IM 渠道（企业微信等）会话不播放提示音，避免打扰

【改进】

- 对话消息不再显示机器人/用户头像，界面更简洁，仅保留智能体名字
- 核心依赖升级（pi 引擎 0.84、Electron 43.3 等），流式协议适配新版本

【修复】

- 修复子代理「全部技能关闭」设置失效的问题
- 适配 pi 0.84 流式协议变更，IM 渠道流式回复恢复稳定
