WA PI Agent 0.2.6 更新内容：

【新增】

- 文件分享（核心）：文件可一键打包部署到 EdgeOne CDN，生成公开分享链接（3 小时有效）。入口覆盖三处——文件树多选后右键「分享所选」、文件预览面板分享按钮、文件修改清单每项分享按钮
- 分享名称：分享时可为链接自定义名称（作为 URL 子路径），全局唯一查重；「我的分享」列表支持铅笔重命名，改名后需重新部署生效；旧版分享数据自动迁移兼容
- 分享管理面板（系统设置 → 分享）：渠道配置（EdgeOne Token 脱敏保存）、自定义域名设置、我的分享列表（复制链接/删除/重命名/打开分享文件夹）、立即部署、清空分享（二次确认，红色警示按钮）、存储用量统计
- 部署进度条：打包 → 上传（真实百分比）→ 部署三阶段实时展示，部署不阻塞主界面

【改进】

- 「我的分享」面板 tab 拆分（分享管理/渠道配置），未部署变更在按钮下方明确提示「需点击立即部署生效」
- 复制链接成功 toast 提示，分享 Token 脱敏下发（前端不再持有明文密钥）
- 文件树多选后普通点击目录自动清除多选并单选，交互更符合直觉
- 弹窗层级优化：分享弹窗点击阴影不关闭（防误触丢输入）、Toast 不被弹窗阴影遮挡

【修复】

- 分享部署必现超时/失败：固定项目全量工作区部署、轮询状态修正、失败终态感知
- 分享重命名改为原子操作（原先先删后复制在部分场景报错丢数据）
- 删除分享的路径穿越校验、未部署的链接刷新返回 409 提示、索引页不再展示文件列表
- 分享路径与预览展示路径对齐（resolvedPath 回退）
- 会话活跃时间口径调整：仅发消息/收到回复刷新，不再因界面停留误判活跃
- 网络错误状态条展示具体原因（不再只有通用文案）；自动重试的新回答正确替换错误消息而非拼接
- 自建网关 Provider 接入链路修复（tokenhub 401/置灰/400）
