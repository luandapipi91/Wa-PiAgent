WA PI Agent 0.10.0 更新内容:

【新增】

- 知识库：把本地文件夹建成知识库（支持 Markdown、Word、PDF、网页等文档），自动扫描与索引，文件变动自动更新，索引进度可视、可取消
- 智能体绑定知识库后，回答自动检索引用库内内容，结果带来源文件与位置，可直接精读原文上下文
- 智能体编辑页支持多选绑定知识库，弹窗内可搜索与批量勾选
- 检索深度重排：开启后检索结果经模型二次精排更精准（模型按需下载，带进度与失败自动降级）
- 知识库健康体检：一键诊断索引过期、缺失、卡死等问题并生成评分报告

【改进】

- 检索结果自动过滤过期内容与近似重复，相关文件优先聚合展示，支持按文档类型与目录过滤
- 底层引擎升级至 1.5.2：发送前压缩判定更准，工具与 MCP 行为契约对齐
- MCP 工具按智能体勾选精确生效

【修复】

- 修复默认工作区新建会话后「项目文件」面板空白的问题
- 修复深度重排开关重启后状态误显「未开启」的问题（重启后自动恢复加载）
