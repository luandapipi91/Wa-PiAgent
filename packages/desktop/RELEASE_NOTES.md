# 0.6.5 更新说明

## 【新增】

- **模型图片输入限制兜底**：所有进入对话历史的图片自动缩放至 4K / 4.5MB 内——覆盖读图、工具截图等此前未压缩的链路，降低 token 消耗并防止网关拒收大图；用户自建网关可在 providers.json 按模型自定义（`inputLimits`）。
- **崩溃现场进诊断**：agent 进程意外退出时，stderr 尾部（含可疑扩展提示）显示到「系统设置 > 诊断」，不再只有退出码。

## 【内核升级】

- pi 0.87.0：会话上下文编辑（ContextEditEntry）、按模型图片输入限制、未知 OpenAI 兼容端点默认不发 strict schema（减少自建网关 400）、崩溃诊断增强等；五条 breaking change 已逐一核实对本应用零影响。
