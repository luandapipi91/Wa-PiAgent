WA PI Agent 0.6.0 更新内容：

【桌宠】

- 多屏修复：右键菜单不再越到另一块屏、青蛙不再自己跳到别的屏、点一下不再原地消失
- 菜单不再超出屏幕（二级菜单按屏幕空间选边）；缩放时菜单不再被截断、也不再跟着窗口跑
- 窗口固定 560×660 + 窗口内部缩放：缩放中心稳定，菜单与宠物位置不再漂移
- 窗口置顶：切到其他应用被点击时宠物不再被遮挡
- 菜单展开期间宠物暂停自发动作（含溜达）；点菜单外的那一下直接生效，不再需要点两次
- 「任务完成」动作收敛为四个（跳一下 / 呱一声 / 喂虫子 / 唱一首）并从互动菜单移除，对话完成后随机挑一个

【定时任务与机器人】

- 模型改为必选：移除「跟随默认」，新建时默认选中第一个可用模型（存量空值编辑时自动归一）
- 定时任务执行会话排除 ask_user_question：无人值守时不再挂起等答复

【修复】

- 子智能体委派中断后部分进度不再丢失（双看门狗误杀路径修复）
