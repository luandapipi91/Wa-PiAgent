# Awesome ChatGPT Prompts（角色提示词参考库）

> 本目录是**外部参考资料**，不接入 hiagent（wa-pi）运行时，仅用于查阅/借鉴角色提示词写法。
> 例外：`agents/` 子目录已按 wa-pi 自定义智能体格式拆分（见下文「agents/ 角色库」），可整目录复制到 `~/.wa-pi/agents/` 直接启用。

## agents/ 角色库

`PROMPTS.md` 的 2096 条角色提示词已按角色拆分为独立文件，存放在 `agents/` 子目录：

- 每个角色一个 `<displayName>.md`，格式为 wa-pi 自定义智能体定义（YAML frontmatter + 正文），与 `packages/kernel/src/agent-md.ts` 序列化格式一致，**可直接被运行时识别**。
- 生成方式：`bun scripts/split-prompts.ts`（幂等，可重复运行）。
- 启用方式：将需要的角色文件（或整个目录）复制到 `~/.wa-pi/agents/`（Windows 默认 `C:\Users\<你>/.wa-pi/agents/`），在智能体列表/新建会话中选择即可。
- 命名规则：displayName 为**中文化角色名**（英文原题翻译为简洁中文，专有名词如 Gemini/Midjourney 等保留原名），清洗非法字符（替换 `/ \ : * ? " < > |` 为 `-`，超 120 字符截断），重名自动追加 `-2`/`-3` 后缀；正文 = 原始提示词，来源贡献者记录在 frontmatter 的 `# Contributed by` 注释中，英文原名记录在 `# Original` 注释中。
- 注意：本目录仍为参考性质，未写入 `DEFAULT_AGENT_SEEDS`，不会自动出现在运行时智能体列表，需手动复制启用。
