界面亮点说明

画布上的连线语义：
• 橙色虚线动画 = 活跃的 ask（阻塞等待中）
• 灰色虚线 = 可通信关系（约束）
• 节点边框颜色 = 状态（蓝=思考/橙=阻塞/灰=空闲）
右侧会话面板：
• Tab 切换 4 个 agent 会话
• intercom ask/send 消息高亮显示
• 阻塞中的 ask 实时倒计时
• 角色图标有未读徽标
底部 Intercom 活动栏：
• 实时显示最新一条 ask/send
• 统计：总消息数、ask 次数、send 次数
• 点击展开完整消息时间线
画布是"约束+监控"，不是"程序"：
• 拖拽 agent 节点 + 连线定义"谁能找谁"
• 运行时 agent 在约束内自由发起 intercom
• 你实时看到谁在 ask 谁、阻塞多久
• 不是按拓扑序执行的 DAG
