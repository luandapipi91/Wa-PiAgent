关键设计点

MCP = 桥接器，不可取消：pi-mcp-adapter 和 pi-intercom 同级，是核心基础设施。它"激活"了 MCP 工具这个来源。
MCP 工具 = agent 级可配：桥接器始终激活，但具体用哪些 MCP server / 工具，每个 agent 独立勾选。研发可以不用 MCP，测试可以用 chrome-devtools。
三类工具并列：内置 / 插件 / MCP 在"能力" tab 下平级展示。从 agent 视角看，web_search 和 chrome-devtools 都是"我能用的工具"，只是来源不同。
能力 ≠ 技能：能力是"工具"（agent 能执行什么动作）；技能是"知识"（agent 知道怎么做某事）。分开两个 tab。
