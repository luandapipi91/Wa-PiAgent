pi-agent-browser-native 作为内置能力

agent 自己用浏览器（做 web 开发时打开 localhost、QA、截图）—— 与产物预览互补

两个浏览器功能，方向相反但都要：
🌐 产物预览（7.4）= 产物 → 用户。agent 生成 login.html，用户在内嵌浏览器看效果。
🤖 agent_browser（本节）= agent → 浏览器。研发做 web 开发时，agent 自己打开 localhost:3000 截图检查、点击 QA。

定位：pi-agent-browser-native 设为内置预装（🔒 不可删），但agent 级启用（不是所有 agent 都需要 —— 产品可能不需要，研发做网页开发需要）。
🌐 产物预览（给用户看）— 7.4
流程：
研发 生成 login.html
↓ write 工具
对话区出现产物卡片
↓ 用户点击预览
用户在内嵌浏览器看效果
实现：Bun 静态服务器 + iframe / WebviewWindow
看到的人：用户
触发：用户点击
🤖 agent_browser（给 agent 用）— 新增
流程：
研发 要做 web 开发
↓ agent 调 agent_browser 工具
打开 localhost:3000，截图，检查元素
↓ 工具返回快照+截图路径
研发 看截图决定怎么改代码
实现：pi-agent-browser-native 扩展（调上游 agent-browser CLI）
看到的人：agent（LLM）
触发：agent 自己调用工具

⚠️ 依赖说明

pi-agent-browser-native 依赖上游 agent-browser CLI
这个扩展本身只是 Pi 的工具包装器，真正驱动浏览器的是 vercel-labs/agent-browser CLI。
WaPi 的处理：
• 启动时检测 agent-browser 是否在 PATH
• 没有则提示用户安装（或在设置里一键安装）
• 检测失败时，agent_browser 工具显示为"未就绪"，但不影响其他能力
