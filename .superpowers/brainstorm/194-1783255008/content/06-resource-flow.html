数据流：从安装到分配

① 装包 → 插件市场 "+ 安装" → pi install npm:pi-web-access
↓ 写入 ~/.pi/agent/settings.json packages 列表
② 分配 → Agent 配置 → 工具 tab → 勾选 web_search → 写入 dev.md 的 tools 字段
↓ 启动时 spawn pi 时 --tools read,bash,web_search
③ 运行 → 研发 agent 只能用分配的工具，没有的就调用不了

关键设计点

内置不可删：pi-intercom + pi-mcp-adapter 锁定。它们提供的能力（intercom/contact_supervisor）始终启用，是委派的前提。
能力是 agent 级的：同样装了 pi-web-access，产品/研发能用 web_search，PM/测试不能用。每个 agent 独立配置。
工具按来源分组：内置工具 / 核心通信（锁）/ 能力扩展（来自已装插件，按插件分组+开关）/ MCP（按 server 分组）。
能力对比表：一眼看到哪个 agent 有什么能力，避免重复配置、发现缺口。
