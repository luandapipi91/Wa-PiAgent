核心设计点

表单 ↔ Markdown 双向同步：所有字段就是 agent.md frontmatter 的可视化编辑。"查看原始 .md" 按钮直接看文件，保存即写盘。
工具是 chip 多选：已启用（绿框）/ 可添加（虚线）。含 intercom（必选，否则无法委派）。MCP 工具自动出现（mcp_*）。
技能 = 分配而非全局：每个 agent 独立配技能列表（inheritSkills: false）。来自不同包的技能都显示来源。
委派规则 = 画布连线："可发起 ask 给"和"可被 ask 自"这两个列表，就是画布上灰色虚线的数据源。改配置 = 改画布。
