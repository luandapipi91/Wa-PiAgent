关键设计决策

Bun sidecar 而非 Tauri 内嵌：避免 Rust ↔ Bun IPC 复杂性。Bun 独立进程崩溃不影响窗口；Tauri 只负责壳子 + 启停 Bun。
pi --mode rpc 而非 SDK 内嵌：每个 agent 独立进程隔离，崩溃可恢复。pi-package-webui 已验证此协议完整可控。
pi-intercom 作编排总线：4 agent 对等通信，ask 阻塞委派精确匹配你的"产品→研发→PM"动态流。
文件系统作真相源：所有状态（session/config/intercom 消息）落盘，Bun 内核重启可恢复。
